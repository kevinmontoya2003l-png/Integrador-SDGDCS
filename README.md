## 📌 Descripción
**NeoApp** es una solución educativa orientada a la **capacitación del personal de salud**, integrando tecnologías modernas como:

- 🐍 Python para análisis de datos  
- ⚛️ React para el frontend  
- ☕ Spring Boot para el backend  

Este repositorio contiene el **módulo de análisis de datos**, enfocado en la exploración, transformación y generación de insights a partir de datos clínicos y operativos.

El objetivo es fortalecer la toma de decisiones basada en datos dentro del sector salud mediante herramientas accesibles y escalables.

---

## 🎯 Objetivos del módulo

- 📊 Procesar y limpiar datos de salud  
- 📈 Generar análisis exploratorios (EDA)  
- 🧩 Preparar datasets para consumo del backend  
- 🧪 Facilitar experimentación con modelos analíticos  
- 📚 Servir como base educativa para formación en data analytics  

---

## 🛠️ Tecnologías utilizadas

- 🐍 Python 3.10+
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib / Seaborn (opcional)
- 📓 Jupyter Notebook
